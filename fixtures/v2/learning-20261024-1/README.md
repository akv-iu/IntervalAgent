# Pinned V2 development evidence

Run `npm run eval:v2:replay`. It needs neither an API key nor a database and writes `results/v2-replay/report.md` and `report.json`. It never substitutes mock or newly generated responses. A missing/incompatible artifact, checksum error, malformed output or accounting mismatch fails closed and writes a failure report instead of leaving an old PASS result. The gate checks that archived scores/eligibility reproduce; an intentionally ineligible candidate is retained and does not make replay itself fail.

`comparisons.json` is an allowlisted selection from the October 24, 2026 live `gpt-6-luna` Phase 3/4 test report on synthetic Northside cases: both complete suite-2 comparisons, including the failed Reviewer target, and the rejected unsafe suggestion. The manifest pins file/source hashes, model, role/suite/SDK versions and the closeout configuration reference. Instructions, typed outputs, tool requests and per-call usage/latency are retained. Workspace access tokens, database configuration and credentials are absent. Hashes detect file changes; they are not a signature proving provider authenticity.

The original harness saved outputs, not exact provider requests. Replay reruns the shared deterministic scoring checks against those outputs; it does not rerun orchestration, execute tools, activate lessons or reproduce a new model's behavior. Scoring reconstructs only the declared `VAL-204` fixture and Denver date from the saved comparison completion timestamp. This is enough for the existing invoice/contact-date checks; it is not an exact prompt transcript. Raw JSON retains all selected outcomes, including failures.

The selection contains **8 paired comparison rows across 2 role contexts and 1 unsafe suggestion**, with **36 captured model calls**. It excludes source dialogue, ordinary lesson-generation/activation/rollback calls, the original suite-1 cycle, ledger transactions and all twelve case journeys. The complete batch had 88 calls; never compare the selected metrics with that batch total as if coverage were identical. Unknown usage is reported separately; the historical conservative token-accounting estimate is not billing/current pricing. Call-latency percentiles use selected individual calls, not user-perceived end-to-end waits. No confidence interval, final holdout, collection-lift or four-agent superiority claim is supported.

The report shares the runtime learning scorer. A scorer change must retain the prior artifact and advance its declared suite; do not silently rewrite failed evidence. Add any future API transport recording under a separately approved phase if it is needed. This set is selected development evidence, not training data or a final holdout.
